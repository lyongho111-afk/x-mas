[크리스마스 HTML 카드 사용 안내]

1. 이 ZIP 파일의 압축을 먼저 풀어주세요. (압축 상태 그대로 열면 브라우저 보안 정책상 이미지가 보이지 않을 수 있습니다.)
2. 대화창에 생성된 배경 이미지를 저장하신 뒤, 'index.html' 파일과 같은 폴더에 넣고 파일 이름을 'background.png' (또는 'image_1pfcL9.png')로 지정하면 자동으로 배경이 적용됩니다.
3. 만약 이미지 파일명이 다르더라도, 웹페이지를 연 후 화면 하단의 [배경 사진 불러오기] 버튼을 누르시면 저장한 이미지를 바로 배경으로 적용하실 수 있습니다.
